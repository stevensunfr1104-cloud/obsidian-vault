## 二、导入方法（选一种）

### 推荐：Inoreader（免费版够用）
1. 打开 https://www.inoreader.com
2. 注册账号（免费版支持150个订阅源）
3. 左侧菜单 → 点击 "+" → "Import OPML"
4. 上传 `SaaS博主订阅合集.opml`
5. 完成

### 备选：Feedly
1. 打开 https://feedly.com
2. 注册账号（免费版支持100个订阅源）
3. 左侧 "Organize" → "Import OPML"
4. 上传文件

### 备选：浏览器插件 Feedbro（完全免费，无需注册）
1. Chrome/Edge 应用商店搜索 "Feedbro"
2. 安装后点击图标 → "Import Feed"
3. 选择 OPML 文件导入

## 三、⚠️ 重要提醒

### 1. B站/微博 UID 可能不准
OPML里B站和微博的RSS链接中，UID是**占位符**（我未逐一核实每位博主的精确UID）。

**解决办法：**
- 导入后如果某个B站/微博源刷不出内容，说明UID错误
- 请手动到B站/微博找到该博主主页，复制UID（数字ID）替换进RSS链接
- 或者直接跳过RSS，在B站/微博App里手动关注此人

### 2. RSSHub 公共实例可能不稳定
`rsshub.app` 是免费公共服务，偶尔会被平台限流或暂时不可用。

**如果刷不出内容：**
- 等几分钟再试
- 或换其他 RSSHub 镜像（如 `rsshub.rssforever.com`）
- 长期稳定方案：自己部署 RSSHub（Docker一键启动，免费）

### 3. 微信公众号/视频号/小红书 = 彻底无解
这三个平台**没有官方RSS**，第三方抓取也不稳定且易被封。

**建议处理方式：**
- 微信公众号：在微信里逐个搜索关注，设星标优先推送
- 视频号：在微信"发现"→"视频号"搜索关注
- 小红书：App内搜索关注，开启"特别关注"推送

## 五、进阶：自动关键词筛选

如果每天RSS更新太多，可以在阅读器里设置**过滤规则**，只保留含以下关键词的内容：

```
SaaS, 企业级, AI应用, 出海, 独立开发, 融资, 产品发布, 增长, MRR, ARR
```

**Inoreader设置路径：**
订阅源 → 右键 "Rules" → "Create a Rule" → 设置关键词过滤

## 六、如果RSSHub不稳定

长期方案：自己部署 RSSHub（完全免费，数据在自己手里）

```bash
# 有Docker的话，一条命令启动
docker run -d --name rsshub -p 1200:1200 diygod/rsshub:latest
```

然后所有链接里的 `https://rsshub.app` 换成 `http://你的服务器IP:1200`
