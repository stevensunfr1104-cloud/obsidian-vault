# 2026-05-07

Karpathy：人的位置 — 什么不能交出去

**核心原则**

"你可以外包你的思考，但不能外包你的理解。"

**可以委托给 Agent**

- API 写法、参数名、语法细节

**必须自己装在脑子里**

- tensor 是什么、view 和 storage 怎么回事
- 底层概念、系统设计约束

**人正在成为瓶颈**

- 不是执行的瓶颈，是理解的瓶颈
- 要知道在做什么、为什么值得做、怎么指挥 Agent

**Karpathy 的学习方法**

每读一篇文章，叠进个人 wiki，让 LLM 从不同角度提问和重组信息。

- 本质：让 LLM 在固定数据上做大量合成数据生成
- 目标：不是让 LLM 替自己读，而是帮自己真正吃透
