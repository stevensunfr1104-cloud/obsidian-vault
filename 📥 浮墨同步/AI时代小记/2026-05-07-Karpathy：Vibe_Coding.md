# 2026-05-07

Karpathy：Vibe Coding vs Agentic Engineering

**Vibe Coding**（氛围编程）

- 核心问题：能不能跑起来？
- 目标：拉高下限
- 面向：所有人

**Agentic Engineering**（智能体工程）

- 核心问题：质量如何保障？出错在哪？能否回滚追责？
- 目标：守住上限
- 面向：必须为结果负责的人

**把 Agent 当实习生，不是神谕**

- 需要清晰任务、边界、checklist、测试、审查
- 它能做真正的活儿，但不会替你承担后果
