# 2026-05-07

Karpathy：LLM 训练的教科书比喻

把 LLM 训练比作教科书三部分：

1. **背景知识** → 预训练（Pretraining）✅ 已大量进行
2. **带解答的例题** → 监督微调（SFT）✅ 已大量进行
3. **练习题** → 强化学习（RL）⚠️ 仍是新兴前沿

"当我们为 LLM 创建数据集时，就像为它们编写教科书一样，需要包含这三种类型的数据。它们必须阅读，也必须练习。"

对开源社区的建议：构建 **多样化的 RL 环境**，帮助激发 LLM 的认知策略。
