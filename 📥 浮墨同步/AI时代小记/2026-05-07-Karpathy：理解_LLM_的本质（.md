# 2026-05-07

Karpathy：理解 LLM 的本质（三个判断）

**1\. LLM 是幽灵，不是动物**

- 没有身体、没有生存压力、没有连续记忆
- 被召唤进上下文，说几句话就消失
- 能力来自人类文字 \+ 奖励函数调教

**2\. 智能不均匀（Jagged Intelligence）**

- 上限：重构十万行代码 / 找出零日漏洞
- 下限："草莓里有几个 r" 数不对
- 它不会因为前一个任务做得好，下一个就不犯傻

**3\. 可验证性是真正的瓶颈**

- 进步快的领域（数学、代码）：有明确验证信号
- 进步慢的领域：验证不了，AI 是"让你越来越自信、但也越来越容易错的机器"
- "你以为是涌现，可能只是有人做了选择。"
