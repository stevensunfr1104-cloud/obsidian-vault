# 2026-05-07

Andrew Ng 核心观点

**核心主张**

企业应优先构建基于 Agentic 工作流的实用应用，而非追逐最强大的基础模型。

**五大论点**

1. 应用开发 \> 模型竞赛 —— "更担心构建有价值的东西"
2. 成本不再是障碍 —— 18 个月成本下降 80%
3. 先构建，后优化 —— "最难的是构建一个能用的东西"
4. Agentic 工作流的进化优势 —— GPT-3.5 + Agentic > GPT-4 零样本
5. 视觉 AI 潜力巨大 —— 处理图像、视频等非结构化数据

**Agentic AI 四大设计模式**

1. 反思（Reflection）— Agent 审视和修正自己输出
2. 工具使用（Tool Use）— LLM 生成代码、调用 API
3. 规划（Planning）— 分解复杂任务，制定执行步骤
4. 多智能体协作（Multi-Agent Collaboration）— 分工协作

**信任与安全的平衡**

- 通过用户培训 \+ 安全护栏降低风险
- 既不应认为 AI 永远不会出错，也不应过度夸大其局限性
