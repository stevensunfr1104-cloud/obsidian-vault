# 2026-04-27

**KMS 精读 \| 3.17 AI业务总结：我们如何选择，降低被颠覆的风险**

来源：ziv-张驰 / 3.2产品组

原文：https://kms.fineres.com/pages/viewpage.action?pageId=1407073927

* * *

**核心命题：** AI 时代，帆软整体的壁垒到底是什么？

**结论：指标中心 \+ 数据治理体系。** 类比「可信知识图谱」之于飞书文档的意义——构建统一数据口径，减少任何 Agent 的幻觉，无论 Agent 来自哪里。

* * *

**各业务线速览：**

1. **FineInsight** — 卖数据 \+ 专家经验内化（沈涛的分析思路），将战略洞察平权化。类比简道云从腰部客户起家。警示：切忌冒进，别直接打 top100 客户。

2. **Clarai** — 内化帆软销售铁军 LTC，帮企业提升转化。红海 CRM 赛道，但 AI 让所有厂商回到同一起点，帆软历史包袱更轻。核心问题：团队内缺销售/LTC 核心建设者，会走弯路。

3. **Dora** — 数据主动找人 \+ AI 异常检测。用硬编排（非自主规划 Agent）保证企业级报告交付的严谨性。警惕：可能被现 BI 产品的 AI 转型吃掉，需持续关注更先进的 Agent 架构。

4. **FDE** — 线索多、商机多，但达摩克利斯之剑：尚未大规模交付，缺交付能力和运维体系建设。

5. **Corevo（能力中台）** — 企业级 Agent 平台（部署在服务器，全员使用，日志可溯源）。差异化：A to A 架构责任清晰；总控 Agent 对接各工具空间总控 Agent，效果好于一个 Agent 掌握 1w 个技能。


* * *

**两个工程方向：**

- 数据工程：指标中心 \+ 可信数据源，向量库/图谱。如何承载飞书式的半结构化知识？目前对客讲故事能力尚不足。
- 算力工程：多模型混合（对标 GenSpark），边缘小模型 + 合规高要求场景分别适配。

* * *

**行动方向：** 越早推出，依托帆软 BI 20 年品牌，越早建立客户心智。与飞书在「数据驱动 vs 知识驱动」上可 1v1 对位。
