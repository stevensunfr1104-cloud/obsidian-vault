## 产品方向
### 当前问题

a、产品体系的规划是有问题的，感受上没有什么连贯性，有的产品对接it，有的服务业务部门，有的往上层应用做，有的往下层数据治理做，这样的产品矩阵推广是比较复杂的

b、产品的商业模式设计偏向于买断型，在复购率上不来的情况下很难大幅提高营收的，只能说缓慢增长做的也比较累，光凭现在的商业模式，纯产品能卖到20亿已经很难

c、产品依赖于项目开发且比重越来越大，尤其是大客户订单，和老客户复购，但项目的利润率是比较低的
### 想法

a、往应用方向做不应该是我们自己做，最好就是发挥生态的优势像苹果一样，在帆软的平台上百花齐放

b、我们自己的产研资源往下去做，数据仓库，数据库方向发力

- 这才是一个大市场，空间足够大，否则这个阶段还在搞一些小打小闹的市场浪费青春
- 基于国产化大背景我们还能吃政策的红利，类似星环/元年以及一众底层数据库厂商都吃到了
- 所谓的信创和自主可控，目前国家统一规划的也都是底层的基座，现在我们的产品参与度很低

c、我们产品规划都是自己搞，搞的时候又不坚决，资源投入不舍得

- 要么不搞，确定一个方向就大力搞，坚决投入，至少五年不动摇，否则不如不搞
- 如果我们自己搞不了，建议考虑**收购和从外面买**（元年也是买的congnos源代码的使用权）
- **如果有的产品短期不适合在帆软平台内孵化但是同学又想做，帆软可以投资同学出去做吗（哪怕各出一半，如果成了帆软可以再收回来）**

## 营销方向

战略共识营好像只负责聊产品规划？市场选择不聊的话怎么能叫做战略共识营呢
### 当前问题

a、产品售卖形式不做选择

从售卖的形式来看有三个：直销/渠道/smb，目前除九数云完全走smb外其余产品没有做分类，均可售
| | **售卖形式** | **产品** | 
| 直销 | 都卖 | 
| 渠道 | 都卖 | 
| smb | 简道云+九数云 | 

带来的问题是

- 不同产品需要不同的销售能力，所有产品都在薅区域直销的资源，但是区域直销的精力和学习能力是有限的
- 成熟产品和探索产品的市场不做选择，带来的问题是公司转型很困难
- 因为没有做分类，直销和渠道冲突不断，帆软公司很难有朋友生态也不够繁荣，越来越多的伙伴离帆软而去，包括广联达，鼎捷等

b、帆软的客户没分层、市场也不做选择（啥都做）

- 很多软件公司巨头的客户都是分层的，微软/华为/oracle原厂只聚焦于做ka客户，其他的客户放出来跟代理商要利润
- 搞过两年na客户，但没有实质性的投入和进展
- 当前营销线的战略是要做央国企，但投入力度和组织没有变革也很难
- 项目组的投入不够聚焦，做了大量中尾客户的项目开导致项目监管难度大利润低

### 想法

a、成熟产品比如finereport去年4.5个亿，今年4个亿市场逐渐萎缩，从新签客户来看边际效应越来越明显，头部客户的fr签的七七八八了，再下沉的市场能不能完全放给渠道来推广？

b、直销只卖头部的3000家客户的fr的运维升级，项目组也只做这3000家客户，其他给供应商来做

c、客户群选择（要么按规模，要么跟用友一样按行业），营销线/产品线的精锐资源往大客户层面投入，大客户利润高，标杆效应明显

总结就是

成熟产品交出来部分市场给渠道做，我们跟渠道要利润

客户群要内部要分层，大客户匹配最优质的营销和产研资源（组织要变革）
