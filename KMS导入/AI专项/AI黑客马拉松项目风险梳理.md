基于往期黑马组织和参与同学调研沟通、以及本次AI黑客马拉松 的验收目标梳理以下风险：
| | **
** | **可能的风险** | **初步对策思考** | 
| 1 | 
**质量&报名吸引问题：**

- 参赛质量
- 资历比较深的同学不好吸引（有自己的目标要忙）
- 怎么吸引前方销售和项目组同学参与，10W奖金分一分对前方同学来说拿个1、2W吸引力可能也不大

 | 
- 每个参赛小组配备导师（ziv/raymond等）
- 除了奖金，还要用新机会吸引，对同学的吸引点：
让做功能产研同学深入到场景中去，深入客户的场景业务，解决客户的实际问题，感受到直接的用户价值
- 内部创业试验田：公司内部的agent创业，又有帆软背书、又有相关资源支撑

 | 
| 2 | 
**组队问题：历史黑马活动前后方各玩各的、难组在一起**

- 前方因为时间精力问题或没组到队伍退赛
- 产研有想做的但是没有前方一起共创、前方有想做的，但是没有产研资源，怎么把前后方同学怎么粘合在一起？

 | 
- 协助组队、比如项目公开招募会，相互匹配
- 上海、华南、国际组东南亚有想法的前方同学较多，可以定点宣传下参赛

 | 
| 3 | 
**场景问题：不清楚有哪些可落地的场景**

- 后方产研需要和前方场景共创，需要能把业务场景最相关的人激发出来

 | 
- 先搞AI场景的搜集，涌现一波内外部需求，激发灵感
- 如果提的人不多，主动采集和做agent调研
- 看看外部公司在做什么，输入一些外部agent信息，比如销售易的销售模拟陪练

 | 
| 4 | 
**要确保能够商业化，参赛项目是客户想要的**

- 避免最后做出来的是无法落地的项目

 | 
- 组织开题报告，对预期解决方案做个描述，评审通过再推进下一步
- 过程中组织月度或相关交流、最佳实践分享，持续对齐预期

 | 
| 5 | 
**项目难度大、验收周期长、落地难度大**

- 要碰到合适的客户且客户愿意跟着我们共创、合适的需求、合适的PM
- 项目经理现在不直接做项目了（给外包做），最后大概率是外包去交付，怎么保障交付质量和落地效果 

 | 
- 里程碑节点验收 
- 想法子助力前方推动客户验证和售卖交付，说服相关人
- 有些信息ziv最好能在上层（marks、dabao、jeff）提前拉通下，尤其是和前方项目组、售前、销售，减少后续推进的阻力

 | 
| 6 | **优秀同学没冒出来、没报名** | 
- 筛选人才盘点优秀人才，定向邀约，找负责人一起
- 把以往参加黑马同学名单拉出来，这部分人群的参与意愿大，定向邀约
- 找一波能跟自己主营业务结合的优秀同学

 | 
| 7 | **并行项目赛道有略多，可能会混乱** | 
- 分顺序开展：先开展AI场景需求搜集和小试牛刀，预告另外两个大项目
- 最好分开管理，一部分人搞一趴，基建部分共享

 | 
| 8 | **主办方和项目运营组缺少业务视角** | 
- 公开招募项目组成员，成员需要覆盖不同职能，前方行业化/售前/销售相关同学参与进来，在后续项目推进能更好调动资源

 |

 |
